# 飞行搭档 / Fluffy Pilots：给文案 agent 看的游戏介绍

改这个文件，文案 agent 下次就会照着写。

- 一款手机和电脑都能玩的网页小游戏，打开网址就能玩，不用下载。
- 玩法：开着小飞机，带上自己的宠物当搭档，点屏幕飞起来，穿过柱子拿分。
- 可以上传自己家宠物的照片，让它变成游戏里的飞行搭档。
- 宠物乐园：宠物会在乐园里走来走去、吃东西、玩。
- 喂食、机库（买飞机皮肤）、桌面宠物、和朋友分享挑战。
- 做游戏的人：NYU 的学生，一个人在做，喜欢小动物。

## 想要的风格

- 可爱、轻松、真实，像一个学生在分享自己做的东西，不像广告。
- 平台：先 Instagram Reels，再 TikTok。
- 不夸大：没有的功能不要写，不要编数字。
